# Make the Journey Atlas primary

The Journey Atlas is the primary professional route through `/journey`, and World Exploration is an optional mode entered only by an explicit Visitor choice. Both presentations use the same canonical Portfolio Records, while WebGL availability, motion preference, device capability, or a decision not to play can never reduce access to evidence. A Physical Visit may create a Passport stamp but never unlocks content. This favors immediate professional comprehension and accessibility over using the 3D world as the mandatory navigation shell.

## Amendment — Direct world entry

The Journey Atlas remains the authoritative, complete professional presentation, but its position as the `/journey` onboarding screen is superseded. The Standard Portfolio Journey Entrance and direct `/journey` navigation now perform a capability check and launch World Exploration automatically when possible, without presenting an Atlas-versus-world chooser. The DOM Journey Atlas and Journey Passport stay available from within World Exploration, and the Journey Atlas opens automatically when the world cannot start. Direct entry changes the presentation order; it does not make World Exploration, a Physical Visit, or Passport progress a requirement for professional evidence.
